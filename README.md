# FIREWALL-USER-INTERFACE-
This project is a user interface that lets users easily change their firewalls protocol while also adding rules to it 
A very important thing about this project is that it only works for Linux and no other OS since it uses the sub process library to run commands directly on the Linux terminal and also it uses the nftables command to configure the firewall which doesn't exist in other operating systems. Also it is very important to know that this code has a big effect on your device and depending on the rules and protocols it may access to some ports making you unable to receive back a packet. In this case try and add that port to your rule set. Overall i believe that this repo will be very useful to those who want to make their devices a bit more secure
